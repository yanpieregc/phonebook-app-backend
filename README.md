# App de Lista de contactos(Back-end)
Aplicación que permite crear, actualizar, buscar y eliminar contactos y sus números telefónicos.

## Front-end
El front-end de este proyecto se encuentra en:
https://github.com/yanpieregc/phonebook-app-frontend

## Tecnologías
- JavaScript
- Node.js
- Express
- MongoDB

## Características
- Listar contactos
- Buscar contactos por nombre
- Agregar nuevos contactos
- Actualizar el número telefónico de un contacto existente
- Eliminar contactos

## Instalación
- pnpm install
- pnpm start
